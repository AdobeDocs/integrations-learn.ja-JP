# Adobe [!DNL Analytics]とExperience [!DNL Platform]の統合

{{analytics-description}}

{{experience-platform-description}}

Adobe [!DNL Analytics]とAdobe Experience [!DNL Platform]を統合すると、次のようなメリットが得られます。

+ 簡単に言えば、**ユーザーインターフェイスがワークフローを開始しました**
+ **ユーザーインターフェイス**&#x200B;をマッピングして[!DNL Analytics]個のpropとeVarを新しいXDM フィールドにコピーする
+ リアルタイム顧客プロファイルと顧客ジャーニー [!DNL Analytics]&#x200B;**から**&#x200B;の値を取得する最速の方法

これらのプラットフォームを統合することで、データを活用して、優れた顧客体験、効果的なマーケティング、競争力を実現できます。
