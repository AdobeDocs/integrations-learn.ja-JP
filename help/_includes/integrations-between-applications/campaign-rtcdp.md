# [!DNL Campaign]とリアルタイム顧客データ [!DNL Platform]

{{campaign-description}}

{{real-time-cdp-description}}

Adobe [!DNL Campaign] Managed Cloud Service DestinationおよびSource コネクタを使用すると、Adobe [!DNL Campaign]とAdobe Experience [!DNL Platform]の間でシームレスに統合できます。 この統合の主な利点は次のとおりです。

+ **Adobe Experience [!DNL Platform]を活用したオーディエンスで[!DNL Campaign]のセグメント化機能**&#x200B;を拡張し、[!DNL Campaign]でそのデータをアクティブ化します。
