# [!DNL Campaign]と[!DNL Target]の統合

{{campaign-description}}

{{target-description}}

Adobe [!DNL Campaign]とAdobe [!DNL Target]を使用して、メールコンテンツをパーソナライズし、最適化します。 主なメリットは次のとおりです。

+ **Adobe [!DNL Campaign] data**: Adobe [!DNL Campaign] data martを使用して、Adobe [!DNL Target]のターゲティングを強化します。
+ **オーディエンスセグメンテーション**：最適化されたターゲティングとパーソナライズされたエクスペリエンスのために、セグメントを訪問者IDにリンクします。
+ **[!DNL Target]機能強化**：重要なデータ（ユーザーエージェント、IP アドレス、位置情報）にアクセスして、ターゲティングとキャンペーンを改善します。
