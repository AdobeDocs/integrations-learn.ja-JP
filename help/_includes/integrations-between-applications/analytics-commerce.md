# [!DNL Commerce] および [!DNL Analytics]

{{commerce-description}}

{{analytics-description}}

Adobe [!DNL Commerce]とAdobe [!DNL Analytics]を統合する主な利点は次のとおりです。

+ **包括的な顧客インサイト**：この統合により、顧客インタラクションの統合ビューが提供され、顧客の行動、好み、購入パターンに関するより深いインサイトを得ることができます。
+ **強化されたマーケティングアトリビューション**: Adobe [!DNL Commerce]とAdobe [!DNL Analytics]のデータを組み合わせることで、マーケターは売上やコンバージョンをより的確なマーケティング活動に結びつけ、より正確なROIの測定と最適化を実現できます。
+ **パーソナライズされた顧客体験**：両方のプラットフォームを統合することで、顧客データにもとづいてパーソナライズされた体験を実現し、より関連性の高い商品レコメンデーション、ターゲットを絞ったオファー、顧客満足度の向上につながります。
+ **効率的なe コマースの最適化**：企業は分析データを使用して、web サイトとユーザーエクスペリエンスの最適化の機会を特定できます。その結果、コンバージョンの増加、カート放棄の減少、e コマース全体のパフォーマンスの向上につながります。
+ **データ主導の意思決定**：この統合により、カスタマージャーニーの包括的なビューが提供され、企業は、実際のインサイトにもとづいて、十分な情報にもとづいたマーケティング、セールス、製品に関する意思決定をおこなうことができるようになり、データ主導の意思決定が可能になります。

全体として、Adobe [!DNL Commerce]とAdobe [!DNL Analytics]を統合することで、データ主導のインサイトとパーソナライズされた体験を組み合わせた強力なe コマースエコシステムが構築され、顧客エンゲージメントの向上、売上の増加、全体的なビジネスの成長につながりました。
