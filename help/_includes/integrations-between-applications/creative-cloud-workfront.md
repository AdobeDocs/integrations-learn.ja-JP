# Creative CloudとWorkfrontの統合

{{creative-cloud-description}}

{{workfront-description}}

Adobe WorkfrontとAdobe Creative Cloudを連携する主な利点は次のとおりです。

+ **Creative ワークフロー**：統合により、タスク、フィードバック、Creative Cloud アプリへのログイン時間が効率化されます。
+ **効率的なコラボレーション**: Workfrontは、クリエイティブな作業のレビュー、承認、チームのコラボレーションを促進します。
+ **生産性の向上**: シームレスな環境の環境設定により、コンテンツの作成速度と品質が向上しました。
