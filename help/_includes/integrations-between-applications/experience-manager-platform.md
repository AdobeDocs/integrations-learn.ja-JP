# Experience ManagerとAdobe Experience [!DNL Platform]

{{experience-manager-description}}

{{experience-platform-description}}

AEMとExperience [!DNL Platform]を統合すると、次のようなメリットが得られます。

+ **データ収集**：顧客の全体像を把握するために、さまざまなソースからデータを収集して統合します。
+ **顧客プロファイル**：行動データ、トランザクションデータ、デモグラフィックデータを使用して、統合プロファイルを作成します。
+ **アクティベーションと統合**：リアルタイム データのアクティベーションとインサイトを実現するために、Adobe製品と統合します。
