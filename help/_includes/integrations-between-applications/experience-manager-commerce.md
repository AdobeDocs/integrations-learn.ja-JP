# Experience ManagerとAdobe [!DNL Commerce]

{{experience-manager-description}}

{{commerce-description}}

[!DNL Commerce]統合フレームワーク（CIF）を使用してAEMとAdobe [!DNL Commerce]を統合すると、次のようなメリットが得られます。

+ **すぐに使えるコマースコンポーネントを使用して、イノベーションを加速**&#x200B;し、カスタムコード要件を削減します。
+ Adobeのクライアントサイドのデータレイヤーを使用して、パーソナライズされたエクスペリエンスを通じてコンバージョン **を促進します。**
+ **AEMのCIF ツールを使用して、リッチでスケーラブルなコマース体験を迅速に構築**。
+ **オーサリングを合理化**&#x200B;し、オムニチャネルの顧客接点をまたいで製品コンテンツを効率的に管理します。
