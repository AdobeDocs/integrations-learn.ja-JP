# [!DNL Analytics]と[!DNL Campaign]の統合

{{analytics-description}}

{{campaign-description}}

Adobe [!DNL Analytics]とAdobe [!DNL Campaign]の統合により、シームレスなデータ共有とメール追跡が可能になり、次の利点が得られます。

+ **KPI データ**&#x200B;をAdobe [!DNL Campaign]からAdobe [!DNL Analytics]に共有します。
+ **Adobe [!DNL Analytics] パラメーターを使用してトラッキング式**&#x200B;をエンリッチします。
+ トリガーを使用して、トラッキングされた特定の行動に基づいて&#x200B;**パーソナライズされたメールを送信**&#x200B;します。
