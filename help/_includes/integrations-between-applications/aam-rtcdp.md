# Audience ManagerとReal-Time CDPの統合

{{audience-manager-description}}

{{real-time-cdp-description}}

Adobe Audience ManagerとAdobe Real-Time CDPを統合すると、次のようなメリットが得られます。

+ **ファーストパーティデータとサードパーティデータを組み合わせた包括的な顧客インサイト**&#x200B;により、顧客の好みや行動をより深く理解できます。
+ **リアルタイムのパーソナライゼーション**&#x200B;により、マーケターは適切なエクスペリエンスを提供し、顧客エンゲージメントと満足度を向上させることができます。
+ **正確なオーディエンスセグメンテーション**&#x200B;により、マーケティング活動が最適化され、より効果的な施策とROIの向上につながります。
+ **シームレスなクロスチャネルエクスペリエンス**&#x200B;により、一貫したメッセージと顧客ロイヤルティを実現できます。
+ **データプライバシーとコンプライアンスの強化** コンプライアンス顧客との信頼関係を構築し、コンプライアンスリスクを軽減します。
