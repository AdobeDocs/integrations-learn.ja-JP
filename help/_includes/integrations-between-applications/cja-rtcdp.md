# 顧客ジャーニー [!DNL Analytics]とReal-Time Customer Data [!DNL Platform] （Real-Time CDP）の統合

{{customer-journey-analytics-description}}

{{real-time-cdp-description}}

Adobe Customer ジャーニー [!DNL Analytics]とAdobe Real-Time CDPを連携する主な利点は次のとおりです。

+ **360度の顧客像**: データを組み合わせて、統合されたカスタマージャーニー像を構築し、インタラクションと嗜好を把握します。
+ **リアルタイムのパーソナライゼーション**:Adobe Real-Time CDPを利用して、適切なエクスペリエンスをすばやく提供できます。
+ **顧客インサイトの深化**：行動とジャーニーを分析し、データ主導の意思決定を通じて戦略を改善します。
+ **シームレスなデータアクティベーション**: データのアクティベーションを合理化し、チャネルをまたいでパーソナライズされたエクスペリエンスを実現します。
+ **強化されたマーケティングアトリビューション**：タッチポイントの影響を正確にアトリビューションし、ROIの測定と最適化を改善します。

全体として、Adobe カスタマージャーニー [!DNL Analytics]とAdobe Real-Time CDPの統合により、企業は優れたカスタマーエクスペリエンスを提供し、顧客エンゲージメントを促進し、包括的でリアルタイムの顧客インサイトにもとづいて、十分な情報にもとづいたマーケティング上の意思決定を行うことができます。
