# Acrobat SignとExperience Managerの統合

{{acrobat-sign-description}}

{{experience-manager-description}}

Acrobat SignとAdobe Experience Manager（AEM）を統合すると、次のような利点があります。

+ **ドキュメントのワークフローを合理化**: AEM Forms内でドキュメントの署名を自動化し、承認を迅速化して、手作業を排除します。
+ **ユーザーエクスペリエンスの向上**：電子サインを有効にし、印刷と郵送を減らして、より迅速で効率的なプロセスを実現します。
+ **正確性とセキュリティの向上**：業界のコンプライアンスと堅牢なセキュリティ機能を遵守しながら、マッピングされたフォームフィールドでデータの整合性を確保します。
+ **モバイルフレンドリーでリモートアクセシビリティ**：あらゆるデバイスで文書に署名し、様々な画面サイズに対応したレスポンシブデザインでリモートワーカーをサポートします。
