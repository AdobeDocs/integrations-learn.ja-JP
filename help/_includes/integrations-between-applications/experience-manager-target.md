# Experience Managerと[!DNL Target]の統合

{{experience-manager-description}}

{{target-description}}

Adobe Experience ManagerとAdobe [!DNL Target]を組み合わせて使用すると、企業がコンテンツを管理し、パーソナライズされたエクスペリエンスを提供できる強力なエンドツーエンド ソリューションが作成されます。 このふたつの基盤の統合により、企業は、web、モバイル、電子メールなどの複数のチャネルをまたいでパーソナライズされたエクスペリエンスをシームレスに提供できるようになります。また、リアルタイムのデータと顧客インサイトにもとづいて、コンテンツ施策とマーケティング施策を最適化できます。

Adobe Experience ManagerとAdobe [!DNL Target]を一緒に使用するメリットには、次のようなものがあります。

+ **エンゲージメントの強化**: AEMとAdobe [!DNL Target]を併用して、カスタマイズされたエクスペリエンスを提供し、満足度とエンゲージメントを向上させます。
+ **プロセスの合理化**: AEMとAdobe [!DNL Target]の統合により、パーソナライゼーションの作成とテストが合理化され、効率が向上しました。
+ **動的な最適化**: AEMとAdobeのリアルタイムの[!DNL Target]統合により、顧客インサイトを活用したコンテンツとキャンペーンの最適化が可能になります。
+ **詳細な分析**: AEMとAdobe [!DNL Target]を組み合わせたデータは、価値ある顧客インサイトを提供し、ターゲットを絞ったマーケティング施策を促進します。
