# [!DNL Analytics]と[!DNL Target]の統合

{{analytics-description}}

{{target-description}}

Adobe [!DNL Analytics]とAdobe [!DNL Target] （A4T）を連携する主な利点は次のとおりです。

+ **データ主導のパーソナライゼーション**: Adobe [!DNL Target]のターゲットアクティビティに[!DNL Analytics]を使用し、パーソナライゼーション戦略を強化します。
+ **統合レポート**: A4T統合は、包括的な分析のために[!DNL Target]と[!DNL Analytics]のレポートを組み合わせています。
+ **最適化されたターゲティング**：正確なオーディエンスセグメンテーションとコンテンツの最適化のために、[!DNL Analytics] データに基づいて決定します。
+ **共有オーディエンス**: [!DNL Analytics]を使用して詳細なセグメントを作成し、それらを[!DNL Target]に共有して、テスト用のオーディエンスとして使用します。
